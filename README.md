# D.investimentos — Terminal Quantitativo HUD & Consultor Larius

Plataforma patrimonial construída do zero com base na síntese de 5 prompts do MotionSites (`aurex-finance`, `iris-assistant`, `data-signal`, `axon`, `vocari-hero`), combinando **Design System Dark-Mode / HUD (Phantom Black & Obsidian)**, **Three.js / GLSL Shaders** e **Engenharia de Prompt Fiduciária CVM 19**.

## Stack Oficial
- **Front-end (`frontend/`):** TypeScript + React + Vite + Tailwind CSS + Three.js (`ShaderMaterial` GLSL customizado).
- **Back-end (`backend/`):** Python + FastAPI + Pydantic v2 (motor de cálculo B3/FIIs, tabela regressiva de IR e camadas de engenharia de prompt do consultor Larius).

## Acesso Web Estático (GitHub / Nuvem)
- [`index.html`](index.html) contém o build compilado do front-end TypeScript (`frontend/dist`) pronto para execução direta em navegador remoto.
